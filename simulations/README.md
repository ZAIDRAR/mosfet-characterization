# Simulations

This folder is for original circuit files and model documentation.

## Starter example

[`nmos-output-educational.cir`](nmos-output-educational.cir) is a **simple ngspice netlist for learning**, not an experimental result. It uses a Level-1 compact model with illustrative parameters.

For **LTspice**, create a schematic with an NMOS transistor, two independent voltage sources (drain and gate), ground source/body, and a documented model. Save it here as `.asc` when you have built and checked it.

Keep any third-party process/model files only when their license allows redistribution.

## Checklist
- Record transistor model and version/source
- Document terminal connections and device dimensions
- Include sweep commands and step size
- Record current sign convention
- Do not upload waveforms or plots that were not actually generated
