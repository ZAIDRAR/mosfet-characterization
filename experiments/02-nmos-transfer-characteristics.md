## Objective

## Procedure

3. Sweep \(V_{GS}\) over a suitable interval (for example 0 to 5 V).
4. Plot \(I_D\) versus \(V_{GS}\) and save input file and waveform.
5. Estimate threshold voltage using a clearly specified method; do not equate the first nonzero simulator sample with a universally defined threshold.
6. If desired, estimate \(g_m\) from the local derivative in a defined operating range.
